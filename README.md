# Портфолио QA: проекты по тестированию

Здесь собраны два проекта, демонстрирующие навыки функционального, регрессионного и визуального тестирования, а также работу с тест‑кейсами и баг‑репортами.

---

## 🖥 Проект 1: Регрессионное тестирование интерактивной веб‑страницы и составление баг‑репортов

**Цель проекта:** подтвердить, что изменения не нарушили существующую функциональность, и обеспечить прозрачную коммуникацию с разработкой через структурированные баг‑репорты.

**Что было выполнено:**
* Составлен план тестирования: 17 тест‑кейсов для проверки ключевых функций.
* Оформлено 10 баг‑репортов с детальным описанием ошибок, присвоены приоритеты и статусы.
* Проведён ретест исправленных багов: для каждого подтверждённого дефекта проверены сопутствующие сценарии.

**Результаты:**
* Подтверждено, что изменения не нарушили работу функциональности.
* Баг‑репорты и подтверждённые исправления понятны разработчикам.
* Снижен риск появления новых ошибок после исправлений.

## 📱 Проект 2: Тестирование мобильного приложения

**Цель проекта:** обеспечить качество мобильного приложения через проверку функциональности, регрессии и соответствия UI‑макетам.

**Что делала:**
* Проводила функциональное и регрессионное тестирование на эмуляторе Android Studio и реальных устройствах.
* Разрабатывала чек‑листы для быстрой проверки ключевых сценариев без избыточных шагов.
* Выполняла визуальное тестирование: сверяла интерфейс с макетами в Figma.

**Достижения:**
* Подготовила более 10 структурированных баг‑репортов, каждый с шагами воспроизведения, ожидаемым и фактическим результатом, оценкой критичности.

**Инструменты:** Android Studio, Figma, скриншоты, чек‑листы.

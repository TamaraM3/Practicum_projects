# Портфолио QA: проекты по тестированию

🧩 Здесь — 4 проекта по тестированию: веб‑приложений, мобильного приложения и API.  

В каждом — артефакты (чек‑листы, тест‑кейсы, баг‑репорты), применение техник тест‑дизайна и фокус на качестве пользовательских сценариев. 📊✨


---

## 📦 Проект 1: Комплексное тестирование стека сервиса доставки (веб, мобильное приложение, REST API)

🏷 Теги: #тестирование #веб #мобильное_приложение #REST_API #Postman #Android_Studio

**Цель проекта:** обеспечить стабильность и корректность работы сервиса доставки за счёт сквозного тестирования всех компонентов: веб‑интерфейса, мобильного приложения и API.

**Что делала:**
* Разработала тест‑кейсы и чек‑листы, покрыв функциональные требования и вёрстку.
* Провела кроссбраузерное тестирование (Яндекс Браузер, Chrome) и проверку адаптивности на разрешениях 1280×720 и 1920×1080; контролировала отсутствие критических наложений и искажений интерфейса.
* Тестировала мобильное приложение на эмуляторах в Android Studio.
* Проверяла REST API через Postman.
* Применяла техники классов эквивалентности и анализа граничных значений для эффективного покрытия сценариев.

**Достижения:**
* Выявлено более 100 дефектов, включая 9 блокирующих, с приоритизацией по влиянию на пользователя.
* Снижены риски критических сбоев в работе сервиса за счёт комплексного тестирования веб‑ и мобильного приложений, валидации REST API в Postman и анализа логов в Android Studio.

**Инструменты:** Android Studio, Postman, скриншоты, чек‑листы и тест‑кейсы.

## 🚗 Проект 4: Тестирование веб‑приложения каршеринга

**Цель проекта:** обеспечить корректность вёрстки и логики ключевых сценариев бронирования и оплаты в веб‑приложении каршеринга.

**Что делала:**
* Изучила требования и макеты в Figma, чтобы выстроить проверки по дизайну.
* Составила чек‑лист из 63 пунктов на вёрстку формы бронирования и элементов навигационной карты.
* Провела тестирование вёрстки в двух окружениях — Яндекс Браузере и Firefox.
* Подготовила чек‑лист из 50 пунктов на логику окон «Способ оплаты» и «Добавление карты».
* Применила техники тест‑дизайна (классы эквивалентности и граничные значения) для эффективного покрытия сценариев.
* Составила тест‑кейсы на логику кнопки «Забронировать».
* Завела 27 баг‑репортов с описанием дефектов.

**Достижения:**
* Структурированные чек‑листы позволили системно проверить как UI, так и логику без пропуска критических сценариев.
* Выявлено и задокументировано 27 дефектов — это помогло команде стабилизировать ключевые пользовательские пути до релиза.

**Инструменты:** Figma, Яндекс Браузер, Firefox, Google Sheets (чек‑листы, тест‑кейсы, баг‑репорты).

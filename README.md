## Проект

Регрессионное тестирование интерактивной веб‑страницы и составление баг‑репорта.

## Выполнено

- Составлен план тестирования для проверки ключевых функций — 17 тест‑кейсов.
- Оформлено 10 баг‑репортов с детальным описанием ошибок, присвоены приоритеты и статусы.
- Проведён ретест исправленных багов: для каждого подтверждённого дефекта проверены сопутствующие сценарии.

## Результат

- Подтверждено, что изменения не нарушили работу функциональности.
- Баг‑репорты и подтверждённые исправления понятны разработчикам.
- Снижен риск появления новых ошибок после исправлений.

**Тестирование мобильного приложения**

Проект по комплексному тестированию мобильного приложения: проверка функциональности, регрессии и соответствия UI‑макетам.

**Что делала:**
* проводила функциональное и регрессионное тестирование на эмуляторе Android Studio и реальных устройствах;
* разрабатывала чек‑листы для быстрой проверки ключевых сценариев;
* выполняла визуальное тестирование: сверяла интерфейс с макетами в Figma.

**Достижения:**
* подготовила более 10 структурированных баг‑репортов (с шагами воспроизведения, ожидаемым и фактическим результатом, оценкой критичности).

**Инструменты:** Android Studio, Figma, скриншоты, чек‑листы.
